# AI 出題與圖解

## 1. 計算題模板

`scripts/ai_questions/` 包含球柱鏡換算、頂點距離、調節、面屈光力、稜鏡、角膜曲率與低視力放大率等模板。每個模板定義參數範圍、解法、干擾選項和解題步驟。題幹會交代公式需要的參考距離、常數或取捨規則。程式碼保留用於重算比對的參考題識別碼與數值參數。

## 2. 程式驗算與模型盲解

1. 產生器以來源題的參數回放解法，核對來源題的答案。缺少來源題或驗算不符時，排除對應模板。
2. 每題檢查數值、選項差距、顯示文字去重和常見的替代計算約定。
3. 選用的 `audit.py` 會打亂選項，交給模型盲解。它記錄模型結果並依一致性篩選輸出。抽查模式可用 `--per-template` 或 `--limit` 控制題數。

產生器需要本機的 `題庫/轉檔/` 與自備的 `題庫/考點.json`。考點檔以 `<場次>/<試卷檔名前綴>/<題號>` 為鍵，將題目對應到 `<單元 ID>#<考點編號>`。可參考 [虛構範例](../examples/考點.json)。需要哪些來源題，可從各模板的 `sources` 查詢。發行在本機建置的 AI 題前，請先檢閱回放和盲解結果。

```sh
python scripts/ai_questions/generate.py
python scripts/ai_questions/audit.py --input 題庫/AI模擬/ai_questions.json --per-template 3 --dry-run
```

`--dry-run` 只試算題數與費用。實際盲解需要環境變數 `ANTHROPIC_API_KEY`，會呼叫外部 API。請保留產生器原始輸出，自行檢查經盲解篩選後的結果再放入 App 的本機題庫。

## 3. 圖解

App 依參數用 SwiftUI 重繪稜鏡、散光焦線、透鏡光路、頂點距離、調節、TABO 軸度、眼外肌與視野圖。計算題圖解會重新核對解題步驟，核對失敗時保留文字解答。

## 4. App 練習

AI 題有自己的錯題與收藏。作答以 `source = "ai"` 記入考點掌握度，權重是歷屆題的一半。FSRS 排程、模擬考、歷屆正確率與讀書夥伴使用歷屆題資料。

### 4.2 資料格式

`題庫/AI模擬/ai_questions.json` 內含題目識別碼、所屬科目與考點、題幹與選項、正解、錯誤選項說明、解題步驟。圖解以 `figure.type` 與 `figure.params` 儲存，可省略。 [虛構 AI 格式範例](../examples/ai_questions.json)
